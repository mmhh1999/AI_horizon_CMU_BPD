# Branch `david`: community context and cost explorer

Local work based on `mso-v0`. Run `python3 -m http.server 8791 --directory src/app` from the repository root and open `http://localhost:8791/`. Use **Try an example lot** for the full path. No server-side API key is required for the built page.

## New information

- **Police-reported activity:** The existing `city/neighborhoods.json` contains Pittsburgh Bureau of Police monthly criminal activity by neighborhood (2024, 2025, partial 2026), downloaded 2026-09-26 from [WPRDC](https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard) and linked to the [City Police Data Portal](https://www.pittsburghpa.gov/Safety/Police/Police-Data-Portal). The new panel displays full-year 2025 counts for NIBRS crimes against persons, property, and society, with a 2024 comparison. It does not feed a score or map ranking. These are recorded incidents, not a measure of personal safety.
- **Smell Pittsburgh:** `src/pipeline/build_smell.py` queries [CMU CREATE Lab's public API](https://github.com/CMU-CREATE-Lab/smell-pittsburgh-rails/wiki/Smell-PGH-API) by month for 2025 reports rated 4 or 5. Public coordinates are already privacy-perturbed. The script joins them to the 90 City neighborhood polygons and writes only counts and monthly totals to `src/app/data/city/smell-2025.json`; it does not export point locations, descriptions, or user information. On 2026-09-26 it fetched 6,061 severe reports across the Allegheny County region, of which 2,985 fell in City neighborhood boundaries. Reports are voluntary; counts depend on participation, reporting practices, and neighborhood boundary uncertainty. They are not pollution concentrations or health exposure estimates. API description: [Smell Pittsburgh data page](https://smellpgh.org/data).
- **Cost explorer:** The default construction slider is $162 per modeled new square foot. This is derived from [NAHB's 2024 national single-family survey](https://www.nahb.org/news-and-economics/housing-economics-plus/special-studies/special-studies-pages/cost-of-constructing-a-home-in-2024): $428,215 construction cost divided by 2,647 finished square feet. The model computes `new modeled floor area × editable $/sq ft + editable contingency + editable land cost`. The ±25% sensitivity band is our scenario assumption. Its application to Pittsburgh, apartments, commercial floor space, and gross floor area is not independently validated; the result is a comparative illustration in 2024 dollars, not a local quote or feasibility study. New floor area excludes building volumes marked as existing. Demolition, rehabilitation, financing, utilities, unusual site work, tax and operations are not estimated.

## Interface

The header shows four stages. The side rail adds **Context** and **Costs** navigation. In a neighborhood, the context panel pairs reported police activity with smell-report frequency. On a parcel, **Context** opens the neighborhood panel; **Costs** jumps to the selected housing type's editable cost estimate. The rest of the scenario engine and stakeholder weights remain as on `mso-v0`.

The Smell file is a reproducible snapshot. To refresh it, run `python3 src/pipeline/build_smell.py` with network access. This script currently targets calendar year 2025 by design; extending the date range requires updating the script and the UI labels together.
